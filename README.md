# Strategy Game

Стратегическая игра на **Unity 6** (6000.4) с **Universal Render Pipeline (URP)**. Стройте базу, создавайте технику и уничтожайте вражеские машины.

## Сюжет

Прошло несколько лет после падения старого мира. Дороги опустели, города превратились в руины, а то, что осталось от армии, разбрелось по пустошам.

Вы командуете небольшим передовым отрядом. Ваша задача: закрепиться на нейтральной территории, построить базу и собрать боевую технику. Но вы не одни. Рядом уже хозяйничают враги, их быстрые боевые машины патрулируют округу и атакуют всех, кто появляется в их зоне.

Постройте оборону, наладьте производство и отвоюйте землю у врага шаг за шагом.

### Постройки

| Постройка | Что делает |
|-----------|------------|
| 🏠 **Дом** | Из него появляются боевые машины. Они стреляют по вражеским машинам. |
| 🏭 **Ангар** | Из него появляются танки. |

Здание можно поставить на карту, предварительно повернув его в нужную сторону.

### Техника

- **Боевые машины**: быстрые, стреляют по вражеским машинам. Появляются из дома.
- **Танки**: тяжёлая техника. Появляются из ангара.

## Управление

| Клавиша | Действие |
|---------|----------|
| **W / A / S / D** | Движение камеры |
| **Q** | Поворот влево |
| **E** | Поворот вправо |
| **Shift** | Ускорение действия: камера двигается быстрее, а здание при постройке вращается быстрее |

## Как запустить проект

1. Установите **Unity Hub** и **Unity 6000.4.3f1** (точная версия указана в `ProjectSettings/ProjectVersion.txt`).
2. Склонируйте репозиторий:
   ```
   git clone https://github.com/B18ack/StrategyGame.git
   ```
3. В Unity Hub нажмите **Add → Add project from disk** и выберите папку проекта.
4. Откройте сцену `Assets/Scenes/MainScene` и нажмите **Play**.

Первый запуск может занять несколько минут: Unity пересоздаёт папку `Library`.
